How does voice-everywhere actually feel?

Voice is the fast path into a field you can still type in — never the only path, and never a pipe that fires the agent before you have seen the words. This demo is a state machine, not a transcriber. Canned takes stand in for your voice so the forks are audible as behaviour: hold vs toggle vs voice-activity, batch-with-Project-terms vs streaming-without, preview vs auto-send. Jargon-term recall is the primary metric; global word error is not. Double-click this file. Nothing is saved.
